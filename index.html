🎵 Music Genre Classification

A machine learning project to predict the genre of music tracks.

📁 Dataset

This project uses the GTZAN Genre Collection, a well-known benchmark dataset containing 1,000 audio tracks (each 30 seconds long) across 10 music genres, including blues, classical, country, disco, hip-hop, jazz, metal, pop, reggae, and rock. All files are in .wav format and sampled at 22,050 Hz. The dataset is balanced with 100 tracks per genre, making it ideal for training and evaluating classification models.

🔍 Methodology

Instead of using external audio libraries like librosa, we designed a complete custom audio processing pipeline using only basic Python libraries such as wave and numpy. We extracted meaningful features from raw audio signals, including:

  • Spectral Centroid, Bandwidth, and Rolloff
  • Zero-Crossing Rate
  • Root Mean Square Energy (RMSE)
  • Estimated Tempo
  • Duration

All features were normalized using min-max scaling. We then applied multiple machine learning algorithms—such as K-Nearest Neighbors, Gaussian Naive Bayes, K-Means Clustering, Support Vector Machine, Decision Tree, and Logistic Regression—to classify the tracks. Each model was trained using an 80/20 train-test split and evaluated on various performance metrics.

📊 Results

Our experiments revealed that traditional models, when paired with well-engineered features, can perform surprisingly well. K-Means Clustering and KNN achieved the highest classification accuracy at 36.44% and 35.04% respectively. Other models like Naive Bayes (30%) and SVM (30.5%) also showed promising results, while Logistic Regression and Random Forests performed moderately.

We also explored how model performance varied across genres, with genres like classical and pop being classified more accurately, and others like jazz and country posing more challenges due to overlapping feature distributions.

📌 Conclusion

This project demonstrates that music genre classification can be effectively tackled using standard machine learning models and handcrafted features. By avoiding deep learning frameworks and external libraries, we gained deeper insights into the inner workings of ML algorithms and signal processing. The results are promising and set a strong foundation for future improvements using more advanced features or hybrid models.
