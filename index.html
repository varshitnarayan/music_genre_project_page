🎵 Music Genre Classification

A machine learning project to predict the genre of music tracks.

📁 Dataset

This project uses a music dataset containing features extracted from audio files, such as tempo, spectral features, and rhythm patterns.

🔍 Methodology

We apply machine learning models including K-Nearest Neighbors, SVM, and Random Forests to classify songs into genres like pop, rock, classical, and more.

📊 Results

Model accuracy and performance metrics are discussed and visualized in the full notebook and HTML report.

📌 Conclusion

The project demonstrates that music genres can be predicted effectively using audio features and standard ML models.
