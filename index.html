🎵 Music Genre Classification

A machine learning project to predict the genre of music tracks.

📁 Dataset

• We used the GTZAN Genre Collection, a popular benchmark dataset for music classification.
• It contains 1,000 audio tracks, each 30 seconds long and sampled at 22,050 Hz.
• The dataset covers 10 genres: blues, classical, country, disco, hip-hop, jazz, metal, pop, reggae, and rock.
• Each genre has exactly 100 samples, making the dataset balanced and suitable for fair evaluation.
• All files are in .wav format and were preprocessed manually using custom Python scripts.

🔍 Methodology

• We designed a custom audio feature extraction pipeline using wave and numpy libraries.
• No external libraries like librosa or scikit-learn were used for feature extraction or model training.
• Extracted features include:
    – Spectral Centroid
    – Spectral Bandwidth
    – Spectral Rolloff
    – Zero-Crossing Rate
    – Root Mean Square Energy (RMSE)
    – Estimated Tempo
    – Duration
• Features were normalized using Min-Max Scaling.
• We applied various machine learning models, trained with an 80/20 train-test split:
    – K-Nearest Neighbors (KNN)
    – Support Vector Machine (SVM)
    – Naive Bayes
    – K-Means Clustering
    – Decision Tree and Random Forest
    – Multi-class Logistic Regression

📊 Results

• Each model was evaluated using accuracy, and in some cases precision, recall, and F1 score.
• K-Means and KNN performed best, showing strong potential for genre classification without deep learning.
• Genres like classical and pop had better prediction scores, while jazz and country were more difficult to distinguish.

📌 Conclusion

• This project shows that effective genre classification can be achieved using traditional ML models and custom-engineered features.
• Despite not using deep learning or advanced libraries, we obtained competitive results using simple, interpretable models.
• The project emphasizes the value of understanding feature behavior, model dynamics, and data preparation.
• Future improvements may include:
    – Extracting more advanced features (e.g., MFCCs)
    – Reducing feature overlap via better dimensionality reduction
    – Trying hybrid models or ensemble approaches
